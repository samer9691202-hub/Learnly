Learnly — النسخة العملية
======================

طريقة التشغيل:
1) فك ضغط Learnly.zip.
2) افتح index.html في متصفح حديث.
   للحصول على دعم أفضل، شغّل المجلد عبر خادم محلي ثابت.

الميزات العملية:
- إضافة كورسات جديدة وتعديل جميع حقولها وحذفها.
- إضافة رابط منصة وصورة عبر رابط أو رفع صورة من الجهاز.
- تعديل التصنيف والحالة والتواريخ والتقييم والتقدم والوصف والفوائد والأقسام.
- بحث وفلترة وترتيب فوري، مع إحصائيات متجددة.
- وضع داكن وفاتح مع حفظ الاختيار.
- تصدير نسخة احتياطية إلى JSON واستيرادها لاحقًا.
- إعادة ضبط المكتبة إلى الكورسات التجريبية الأصلية.

حفظ البيانات:
تحفظ التعديلات محليًا في المتصفح على هذا الجهاز، ولا تُرسل إلى خادم.
استخدم زر «تصدير» بانتظام لحفظ نسخة احتياطية، خصوصًا قبل مسح بيانات المتصفح أو تغيير الجهاز.
صور الكورسات المرفوعة تُضمّن في البيانات وقد تجعل ملف النسخة الاحتياطية كبيرًا.

ملاحظة: البيانات الافتراضية تجريبية، ويمكن تعديلها أو حذفها بالكامل.
